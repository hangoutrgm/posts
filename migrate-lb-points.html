🏆 LB Points Backfill

Copies every user's all-time users/{uid}/lbPoints (wins + host bonuses) into the current leaderboard period buckets (lbWeekly/{thisWeek}/{uid} and lbMonthly/{thisMonth}/{uid}).

This is a SET (not an increment): it writes the full lbPoints balance, so it is idempotent — re-running produces the same totals.

⚠️ One-time admin tool — read the warnings before clicking.
  • Only correct while you are still inside the first week/month of the site (all-time lbPoints were all earned in that one period). It sets the current period only — do NOT use after the week has rolled over and points have crossed into a new period.
  • It will overwrite any partial counters already written to the current week/month (e.g. the 10 host-bonus points you saw). That is intended — the full balance is the correct total for this first period.
  • You must be signed in as an Admin in this browser. Requires the RTDB rules to allow users/.read (already enabled).
